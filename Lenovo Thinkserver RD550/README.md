# Lenovo ThinkServer RD550

Unbundled BIOS and TMS/BMC.  
To unpack the bundled BIOS/BMC packs, simply run the .exe on a WindowsPC to unpack the content.  
You will the be presented with a .bdl -file.  
Unpack this file with 7Zip.  
Unpack the unpacked file again with 7Zip.  
Voila, the files will be in the new directory.
